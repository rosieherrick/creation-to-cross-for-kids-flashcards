# [Creation to the Cross - for Kids - Flash Cards](https://rosieherrick.github.io/creation-to-cross-for-kids-flashcards/)

## About

`Creation to the Cross - for Kids - Flash Cards` provides a set of flash cards from Creation to the Cross content designed to help kids learn in a fun and interactive way. The flash cards cover key events and concepts from the Bible, making it easier for kids to learn and remember important lessons.
